هوش مصنوعی

AI نام حوزه‌ای گسترده است که به ساخت سیستم‌هایی برای انجام وظایف هوشمندانه مربوط می‌شود.

یادگیری ماشین

Machine Learning یکی از روش‌های مهم AI است؛ در آن مدل با داده‌ها الگو یاد می‌گیرد و برای ورودی جدید پیش‌بینی یا تصمیم تولید می‌کند.

یادگیری عمیق

Deep Learning زیرمجموعه‌ای از یادگیری ماشین است که از شبکه‌های عصبی چندلایه استفاده می‌کند و در کارهایی مثل تصویر و زبان بسیار مهم شده است.

جمع‌بندی

AI چتر بزرگ است، ML یکی از رویکردهای اصلی آن و Deep Learning یکی از شاخه‌های ML است. این تفاوت برای فهم اخبار و ابزارهای هوش مصنوعی مفید است.
