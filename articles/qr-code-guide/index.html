QR Code چیست و چگونه کار می‌کند؟

QR Code یک کد دوبعدی است که می‌تواند اطلاعاتی مثل متن یا یک نشانی وب را در خود نگه دارد.

انتشار: ۲۹ مرداد ۱۴۰۵ · توسط ردلایت
QR

کاربردها

منو، لینک، اطلاعات تماس و پرداخت از نمونه‌های رایج استفاده از QR Code هستند.

نکته امنیتی

قبل از باز کردن لینک، نشانی مقصد را بررسی کنید؛ ظاهر یک کد به‌تنهایی قابل اعتماد بودن مقصد را تضمین نمی‌کند.

جمع‌بندی

QR Code ساده است، اما مثل هر لینک دیگری باید مقصد آن را با دقت بررسی کرد.
