اخبار سخت‌افزار و گیمینگ · ۶ دقیقه مطالعه

قابلیت امنیتی جدید ویندوز ۱۱ ممکن است روی اجرای بازی‌ها اثر بگذارد

مایکروسافت در حال گسترش Memory Integrity است؛ قابلیتی که امنیت هسته ویندوز را بالا می‌برد اما روی برخی سیستم‌های قدیمی می‌تواند نرخ فریم را کاهش دهد.

بازنویسی: ۸ سپتامبر ۲۰۲۶ · توسط ردلایت

Memory Integrity چیست؟

این ویژگی بخشی از Virtualization-based Security است و اجازه نمی‌دهد درایور یا کد نامطمئن به بخش‌های حساس هسته سیستم دسترسی پیدا کند. هدف اصلی، سخت‌تر کردن اجرای بدافزارها و درایورهای مخرب است.

چرا گیمرها باید توجه کنند؟

پردازش‌های امنیتی سطح هسته ممکن است در بعضی بازی‌ها و روی پردازنده‌های قدیمی، مقدار کمی از عملکرد را مصرف کنند. مایکروسافت می‌گوید اثر روی سخت‌افزارهای جدیدتر کمتر است، اما نتیجه برای همه سیستم‌ها یکسان نیست.

کاربر چه کاری می‌تواند انجام دهد؟

وضعیت این گزینه از مسیر Windows Security و بخش Core Isolation قابل بررسی است. خاموش‌کردن آن ممکن است برای عیب‌یابی عملکرد مفید باشد، اما از نظر امنیتی بهتر است پس از پایان بازی دوباره فعال شود.

جمع‌بندی

این خبر یادآوری می‌کند که امنیت و عملکرد همیشه کاملاً هم‌جهت نیستند. کاربران لپ‌تاپ‌ها و رایانه‌های قدیمی بهتر است بعد از به‌روزرسانی ویندوز، نرخ فریم و پایداری بازی‌هایشان را بررسی کنند.
